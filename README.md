# Scramjet Demo

A Scramjet demo page hosted on GitHub Pages, because why not?

## Latest update — November 13, 2026

This demo has been updated to **libcurl.js 0.7.5** for a smoother browsing experience.

## Update policy

I'll keep the dependencies up to date when an update is useful, but I won't chase version numbers just for the sake of being current.

- **Stability first.** A version that works well is worth keeping.
- **Meaningful updates matter.** I'll prioritize releases that bring useful improvements or fixes.
- **No unnecessary upgrades.** If the newest release is less stable, or an older release already does the job just as well, I'll stick with the version that works until there's a good reason to change.
